# Jobscan — Concept 2

Вёрстка концепта из Figma
([Jobscan → Concept 2, node 67:1271](https://www.figma.com/design/9zsPxPC1Skxy98Qe10G3Yl/Jobscan?node-id=67-1271)).

Обычные HTML + CSS + JS, без сборки и зависимостей. Чтобы посмотреть, откройте `index.html`
через любой статический сервер:

```bash
python3 -m http.server 8000   # http://localhost:8000
```

Для GitHub Pages ничего собирать не нужно: достаточно опубликовать корень репозитория.

## Структура

```
index.html
css/fonts.css     @font-face для локальных шрифтов
css/styles.css    стили; все размеры в пикселях макета (холст 1440×810)
js/main.js        лоадер, анимация по скроллу, зона загрузки резюме
assets/
  fonts/    Geist Mono, DM Mono, Libre Baskerville, Tinos, DM Sans (woff2, латиница, OFL)
  images/   горы из ASCII, дымка, текстура зоны загрузки, портрет, надпись Jobscan в лоадере, пунктиры
  icons/    SVG-иконки из Figma
  logos/    логотип Jobscan, логотипы ATS (маски) и компаний
```

## Как устроена страница

Секция в Figma — это раскадровка из шести кадров, на странице они идут друг за другом:

1. **Loading** (00% → 57% → 100%). Проценты считают реальную загрузку (картинки, шрифты,
   `window.load`), но не быстрее ~3,6 с. Подпись печатается по буквам; на 50% «Initializing Autopilot Engine...»
   стирается и набирается «Mapping high-stakes career topography...». Лоадер уходит, только когда она допечатана.
2. **Desktop 1**: первый экран. После лоадера синяя панель открывается шторкой справа налево, горы
   приближаются, меню опускается по пунктам, заголовок поднимается по словам из-под маски с размытием,
   под «12 years pioneering ATS research» прорисовывается пунктир, абзац проявляется по словам, затем поднимаются зона
   загрузки, карточки вакансий, плашка «Analyzing 1,400+ executive roles...» и логотипы ATS.
3. **Desktop 2 → Desktop 3**: при прокрутке синяя панель Autopilot раскрывается на весь экран.
   Карточка Backend Developer выходит из стопки поверх Python Developer, остальные карточки исчезают,
   появляются шаги Match / Optimize / Approve / Apply & Track и результат матчинга, цифры считаются от нуля.
4. **Desktop 4**: панель уезжает вверх, а карточка, результат матчинга, шаги и подпись уходят вверх
   чуть быстрее неё (ничего не исчезает), так что в оставшейся полосе панели их уже не видно.
   Снизу выходит секция «Built to Outsmart…» с логотипами.

Каждый элемент интерполируется между своими точными координатами в кадрах (массивы `F` в `js/main.js`),
поэтому в контрольных точках прокрутки страница совпадает с макетом.

## Заметки о точности

- Всё рисуется на холсте 1440×810 и масштабируется по ширине окна: при 1440px это ровно 1:1,
  при 1920×1080 — ×1,333 с теми же пропорциями. Если окно шире, чем 16:9 (например, невысокий ноутбук),
  холст вписывается по высоте, чтобы ничего не обрезалось снизу, а лишнюю ширину забирает синяя панель;
  центрированные элементы остаются по центру, логотипы в последней секции — у правого края.
  Это десктопный макет, мобильной версии в нём нет.
- Карточки вакансий в кадрах — одна и та же карточка в разных масштабах (245, 293, 359, 435, 540px),
  поэтому она свёрстана один раз в размере Desktop 3 и масштабируется трансформом.
- Стёкла в Figma с эффектом glass: светлая кромка 1px, а размытие захватывает то, что за краем.
  Кромка повторена `inset`-тенью, размытие сделано слоем с запасом за край, обрезанным маской.
- Пунктир под «12 years pioneering ATS research» нарисован так, как его рендерит Figma
  (штрих 2px каждые ~12,6px). Пунктир зоны загрузки — SVG с `stroke-dasharray: 8 8`.
- Зелёная картинка «image 30 1» из Desktop 2/3 в макете полностью закрыта непрозрачными горами,
  поэтому в проект не добавлена.
- В Desktop 1 у задней карточки нет статуса «open» и чип «124 feedbacks» стоит у правого края
  (node 92:243); при переходе к Desktop 2 чип сдвигается и появляется статус, как в макете.
- Меню с пунктирной рамкой в Desktop 4 лежит за пределами кадра (y = −290) и не видно, поэтому не свёрстано.
